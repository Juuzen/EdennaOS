# Lingue e testi

Edenna OS è in **italiano** e **inglese**. Si parte sempre in italiano. Il pulsante con la sigla della lingua (**IT**/**EN**), nella barra in basso a destra, passa all'altra lingua al volo, senza chiudere le finestre aperte.

La lingua torna all'italiano a ogni riavvio, e a ogni reset della postazione (Ctrl+Alt+Shift+R): ogni giocatore parte dalla stessa situazione.

## Dove stanno i testi

Ogni pacchetto ha i propri dizionari, vicino al codice che li usa:

| Cosa | Dove | Tono |
|---|---|---|
| Interfaccia di sistema: desktop, finestre, barra, menu, dialoghi | `packages/core/src/locales/{en,it}.ts` | neutro |
| Gestione risorse (Esplora risorse di ProzillaOS) | `packages/apps/file-explorer/src/locales/` | neutro |
| Note di servizio (Editor di testo di ProzillaOS) | `packages/apps/text-editor/src/locales/` | neutro |
| Archivio documenti | `edenna/src/apps/archivio/locales/` | Edenna |
| Testi generali di Edenna (nomi dei luoghi) | `edenna/src/locales/{it,en}.ts` | Edenna |
| **Voce Edenna**: modifiche ai testi neutri | `edenna/src/locales/overrides.ts` | Edenna |

I testi si dividono in due livelli:

1. **Traduzione neutra** (in `packages/`): l'italiano "normale" di un sistema operativo, come "Spegni" o "Chiudi". La si tocca solo per correggere errori di traduzione.
2. **Voce Edenna** (in `edenna/src/locales/overrides.ts`): le frasi che la Edenna Industries dice in modo diverso. Per esempio "Spegni" diventa "Termina sessione", "Ok" diventa "Ricevuto", un errore diventa "Anomalia non classificata". Si indicano solo i testi che cambiano, in entrambe le lingue.

> La voce Edenna attuale è una **prima bozza**. Il registro è formale (si dà del "Lei"), rassicurante e un po' troppo cortese: il sistema non sbaglia mai, al massimo "sospende" o "riallinea".

## Cambiare un testo

**Un testo dell'interfaccia di sistema, con il tono Edenna.** Si cerca la chiave nel dizionario neutro (per esempio `home.shutDown` in `packages/core/src/locales/en.ts`) e la si aggiunge a `edenna/src/locales/overrides.ts`, in italiano e in inglese:

```ts
defineOverrides(coreTranslations, {
	it: { home: { shutDown: "Termina sessione" } },
	en: { home: { shutDown: "End session" } },
}),
```

**Un testo di un'app Edenna** (per esempio l'Archivio). Si modifica direttamente `edenna/src/apps/archivio/locales/it.ts` e `en.ts`.

**Testi con valori variabili.** `{nome}` viene sostituito dal valore corrispondente: `"Apri in {app}"` diventa "Apri in Gestione risorse".

**Plurali.** Si usa `plural()`, che sceglie la forma giusta in base a `{count}`:

```ts
items: plural({ zero: "Nessun elemento", one: "{count} elemento", other: "{count} elementi" }),
```

## Testi di un'app nuova

Quando si crea un'app in `edenna/src/apps/`, si copia la struttura dell'Archivio:

```
edenna/src/apps/nome-app/locales/
  it.ts      testi in italiano: definisce le chiavi
  en.ts      stessi testi in inglese (TypeScript segnala le chiavi mancanti)
  index.ts   defineTranslations("edenna-nome-app", { en, it })
```

Nel componente:

```tsx
const { t } = useTranslation(nomeAppTranslations);
return <button title={t("toolbar.save")}>{t("toolbar.save")}</button>;
```

Nella definizione dell'app, `.setTranslations(nomeAppTranslations)`. Il nome e la descrizione dell'app vengono letti dalle chiavi `app.name` e `app.description`, e cambiano con la lingua.

## Aggiungere una lingua

1. Aggiungere il file della lingua (per esempio `fr.ts`) a ogni dizionario in `packages/` e in `edenna/`, e registrarlo nel rispettivo `index.ts`. TypeScript segnala le chiavi mancanti.
2. Aggiungere la lingua a `EDENNA_LOCALES` in `edenna/src/locales/index.ts`. Il pulsante passerà da una lingua all'altra in ordine.
3. Se serve, aggiungere gli override della voce Edenna in `overrides.ts`.

Se una chiave manca in una lingua, si usa l'inglese.

## Cosa non si traduce

- **Il contenuto dei documenti `.edoc`**: è materiale di gioco, e oggi esiste solo in italiano.
- **I nomi di file e cartelle** del filesystem virtuale: sono dati, e cambiarli cambierebbe i percorsi. Fanno eccezione i collegamenti sul desktop, che mostrano il nome dell'app o del luogo nella lingua corrente.
- **I messaggi per sviluppatori** (console, errori interni).
- **Il terminale e i comandi shell** di ProzillaOS: Edenna non li usa.
- **Le app di ProzillaOS non installate** (Impostazioni, Browser, Calcolatrice…).

## Controlli automatici

- **TypeScript**: ogni lingua deve avere tutte le chiavi del riferimento, e una chiave scritta male nel codice è un errore di compilazione.
- **Test** (`packages/core/test/features/i18n/`): ricerca dei testi, plurali, lingue di riserva, override, completezza delle traduzioni di core.
- **ESLint** (`react/jsx-no-literals`): nei pacchetti tradotti e in `edenna/src` un testo scritto direttamente nel JSX (`<p>Ciao</p>`) blocca il lint. I testi vanno messi nei dizionari, oppure tra graffe se non vanno tradotti (`{"EDENNA INDUSTRIES"}`).

## Barra in basso

L'indicatore di **data e ora** è nascosto: i giocatori non devono sapere in che giorno, o in che anno, si trovano. Si nasconde da `edenna/src/App.tsx`, senza modificare ProzillaOS:

```tsx
<Indicators renderCalendar={EmptySlot}/>
```

Per mettere qualcosa al suo posto basta sostituire `EmptySlot` con un componente. Alcune idee da sviluppare:

| Idea | Cosa mostra | Note |
|---|---|---|
| **Timer di turno** | "Turno 01:24:37": il tempo dall'inizio della sessione, senza mai dire che ore sono | Utile anche allo staff per sapere da quanto un gruppo è alla postazione |
| **Identificativo operatore** | "Interno A-0147", diverso per ogni postazione | Impostabile da configurazione o dalla riga di comando di Electron |
| **Stato del Chip** | Un'icona "Stabile / Sincronizzazione / Anomalia" | Lo staff la cambierebbe durante la sessione per eventi narrativi: serve un canale di controllo (scorciatoia segreta o rete locale) |
| **Comunicazioni aziendali** | Una campanella con messaggi Edenna | Come sopra, i messaggi verrebbero inviati dallo staff |
| **Data fittizia** | "Giorno 1 di permanenza", senza anno | Dà un riferimento temporale interno alla finzione |

Altri indicatori da valutare:

- **Batteria**: sui portatili mostra la percentuale reale, un'informazione del mondo esterno come la data. Si nasconde allo stesso modo: `renderBattery={EmptySlot}`.
- **Volume**: mostra sempre "100%", è solo decorativo.
- **Rete**: con la voce Edenna, "Connessione protetta".

## Limiti noti

- La **conferma di spegnimento** usa la finestra di dialogo nativa del sistema (`window.confirm`): il testo è tradotto, ma l'aspetto non è quello di Edenna OS.
- Il tipo dei file `.edoc` nelle proprietà appare come "Documento (.edoc)": si potrà aggiungere un nome dedicato.
- I **documenti `.edoc` in inglese**: se serviranno, l'Archivio potrà cercare una versione per lingua (per esempio `documents/en/benvenuto.edoc`) e usare l'italiano come riserva.

## Riferimento rapido delle API

Sono tutte esportate da `@prozilla-os/core`.

| API | Uso |
|---|---|
| `defineTranslations(namespace, { en, it })` | Definisce i dizionari di un pacchetto o di un'app |
| `defineOverrides(definizione, { it: {...}, en: {...} })` | Modifica alcuni testi di un altro pacchetto |
| `plural({ one, other, zero? })` | Forme plurali |
| `useTranslation(definizione?)` | Nei componenti: `t`, `locale`, `formatDate`, `nextLocale`… Senza argomenti usa i testi di core |
| `useLocale()` | Solo la lingua corrente: il componente si aggiorna quando cambia |
| `systemManager.i18n` | Fuori dai componenti: `translate`, `setLocale`, `subscribe`… |
| `config.locale` di `<ProzillaOS>` | `locale`, `fallbackLocale`, `availableLocales`, `overrides` |
| `config.virtualDrive.quickAccess` | Cartelle nella barra laterale di Gestione risorse e nel menu Home |
